🟢 الجملة الشرطية الصفرية - Zero Conditional

تُستخدم للتعبير عن الحقائق العلمية والعامة

📐 الصيغة

If + Present Simple, Present Simple

إذا (الشرط بأزمنة المضارع البسيط)، (النتيجة بأزمنة المضارع البسيط)

If + S + V1/V5, S + V1/V5
الشرط: المضارع البسيط ← النتيجة: المضارع البسيط

💡 متى نستخدمها؟

• الحقائق العلمية (If you heat water to 100°C, it boils.)
• العادات والروتين (If I wake up early, I exercise.)
• القوانين الطبيعية (If the sun rises, it gets bright.)

📝 أمثلة على الشرطية الصفرية
الشرط (If)النتيجةالترجمة🔊
If you heat ice, it melts. إذا سخنت الجليد، يذوب.
If it rains, the ground gets wet. إذا تمطر، تبلل الأرض.
If you mix red and blue, you get purple. إذا خلطت الأحمر والأزرق، تحصل على البنفسجي.
If you eat too much, you gain weight. إذا أكلت كثيراً، تزداد وزنك.
If the sun sets, it gets dark. إذا غربت الشمس، يصبح الظلام.
If you study hard, you pass the exam. إذا درست بجد، تجتاز الامتحان.

⚠️ ملاحظة

يمكن استخدام When بدلاً من If في الشرطية الصفرية لأنها تعني نفس الشيء في هذه الحالة.

🔵 الجملة الشرطية الأولى - First Conditional

تُستخدم للتحدث عنṼ верояبية حدث مستقبلي

📐 الصيغة

If + Present Simple, will + V1 (base form)

إذا (الشرط بأزمنة المضارع البسيط)، (النتيجة: will + الفعل الأساسي)

If + S + V1/V5, S + will + V1
الشرط: المضارع البسيط ← النتيجة: will + الفعل الأساسي

💡 متى نستخدمها؟

• أحداث مستقبلية واردة (If it rains tomorrow, I will stay home.)
• تهديد أو تحذير (If you don't study, you will fail.)
• عروض ووعود (If you help me, I will help you.)

📝 أمثلة على الشرطية الأولى
الشرط (If)النتيجةالترجمة🔊
If it rains tomorrow, I will stay at home. إذا تمطر غداً، سأبقى في المنزل.
If you study hard, you will pass the exam. إذا درست بجد، ستنجح في الامتحان.
If she comes, I will tell her. إذا جاءت، سأخبرها.
If I have time, I will visit you. إذا كان لدي وقت، سأزورك.
If you don't hurry, you will miss the bus. إذا لم تستعجل، ستفوت الحافلة.
If the weather is nice, we will go to the beach. إذا كان الطقس جميلاً، سنذهب إلى الشاطئ.

🔄 بدائل will

يمكن استخدام can / may / might / should بدلاً من will حسب المعنى:
If you finish early, you can leave. | If it rains, we might stay home.

🟡 الجملة الشرطية الثانية - Second Conditional

تُستخدم للتحدث عن أحداث غير واردة أو خيالية في الحاضر

📐 الصيغة

If + Past Simple, would + V1 (base form)

إذا (الشرط بأزمنة الماضي البسيط)، (النتيجة: would + الفعل الأساسي)

If + S + V2, S + would + V1
الشرط: الماضي البسيط ← النتيجة: would + الفعل الأساسي

💡 متى نستخدمها؟

• أحداث غير واردة أو مستحيلة (If I were a bird, I would fly.)
• نصائح (If I were you, I would study more.)
• تمني وvenir (If I had more money, I would travel.)

📝 أمثلة على الشرطية الثانية
الشرط (If)النتيجةالترجمة🔊
If I were rich, I would buy a big house. لو كنت غنياً، لاشتريت منزلاً كبيراً.
If I were you, I would apologize. لو كنت مكانك، لاعتذرت.
If she had more time, she would learn French. لو كان لديها وقت أكثر، لتعلمت الفرنسية.
If I lived in Cairo, I would visit the pyramids every day. لو عشت في القاهرة، لزرت الأهرامات كل يوم.
If it weren't raining, we would go out. لو لم يكن المطر يهطل، لخرجنا.
If I could fly, I would travel the world. لو كنت أستطيع الطيران، لسافرت حول العالم.

⭐ ملاحظة مهمة: uses of "were"

في الشرطية الثانية، نستخدم were بدلاً من was مع جميع الضمائر (I/he/she/it):
If I were rich... | If he were here... | If she were my friend...

🔴 الجملة الشرطية الثالثة - Third Conditional

تُستخدم للتحدث عن أحداث لم تحدث في الماضي والندم عليها

📐 الصيغة

If + Past Perfect (had + V3), would have + V3 (past participle)

إذا (الشرط: had + الفعل الثالث)، (النتيجة: would have + الفعل الثالث)

If + S + had + V3, S + would have + V3
الشرط: had + الفعل الثالث ← النتيجة: would have + الفعل الثالث

💡 متى نستخدمها؟

• ندم على أمر لم يفعله (If I had studied, I would have passed.)
• نتائج أحداث ماضية خيالية (If he had come, we would have had fun.)
• انتقاد ما حدث (If you had told me, I would have helped.)

📝 أمثلة على الشرطية الثالثة
الشرط (If)النتيجةالترجمة🔊
If I had studied, I would have passed the exam. لو كنت درست، لنجحت في الامتحان.
If she had left earlier, she would have caught the train. لو كانت غادرت مبكراً، لالتقطت القطار.
If we had booked tickets, we would have seen the match. لو كنا حجزنا تذاكر، لشاهدنا المباراة.
If you had told me, I would have helped you. لو أخبرتني، لساعدتك.
If it hadn't rained, we would have gone camping. لو لم تمطر، لذهبنا لالتخيم.
If he had been there, he would have known the answer. لو كان حاضراً، لكان يعرف الجواب.

🟣 الجملة الشرطية المختلطة - Mixed Conditionals

تجمع بين الشرطية الثانية والثالثة لأحداث متشابكة الزمان

📐 النوع الأول: الماضي يؤثر على الحاضر

If + Past Perfect, would + V1

الشرط: had + الفعل الثالث ← النتيجة: would + الفعل الأساسي

(حدث في الماضي يؤثر على الحاضر)

📐 النوع الثاني: الحاضر يؤثر على الماضي

If + Past Simple, would have + V3

الشرط: الماضي البسيط ← النتيجة: would have + الفعل الثالث

(عادات الحاضر تؤثر على نتائج الماضي)

📝 أمثلة على الشرطية المختلطة
النوعالشرطالنتيجةالترجمة🔊
الماضي → الحاضر If I had studied medicine, I would be a doctor now. لو كنت درست الطب، لصرت طبيباً الآن.
الماضي → الحاضر If she hadn't moved to Paris, she would still live in Cairo. لو كانت انتقلت إلى باريس، كانت لا تزال تعيش في القاهرة.
الحاضر → الماضي If I spoke French, I would have taken that job in Paris. لو كنت أتحدث الفرنسية، لقبلت تلك الوظيفة في باريس.
الحاضر → الماضي If he weren't so lazy, he would have finished the project. لو لم يكن كسولاً إلى هذا الحد، لكان أنهى المشروع.
